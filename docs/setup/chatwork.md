# Chatwork の設定

## 1. API トークン

1. Chatwork にログイン → 右上のアカウント名 → サービス連携 → **API Token**
2. パスワードを入力して表示されるトークンを `.env` の `CHATWORK_API_TOKEN` に設定

> 組織契約の場合、管理者が API の利用を許可している必要があります。

## 2. Webhook（推奨）

Webhook を設定すると受信が即時になります。設定しなくても 5 分ごとのポーリングで取り込みます。

1. サービス連携 → **Webhook** → 新規作成
2. Webhook URL: `https://<公開URL>/webhooks/chatwork`
3. イベント: **アカウントイベント**（自分宛メンション／全メッセージ）を選択。ルームイベントを使う場合は依頼者ごとのルームを追加
4. 作成後に表示される **トークン** を `.env` の `CHATWORK_WEBHOOK_TOKEN` に設定（署名検証に使います）

> Chatwork の Webhook は失敗時に再送されず、連続で失敗すると自動停止します。アプリは常にポーリングも併用するため、取りこぼしはポーリングで補われます。

## 3. 通知先

返信待ちの期限超過や朝のダイジェストは **マイチャット** に投稿します。特定のルームに送りたい場合は `CHATWORK_NOTIFY_ROOM_ID` にルーム ID（URL の `#!rid` の後ろの数字）を設定してください。

## 4. 依頼者の紐付け

依頼者ごとのルーム（グループチャットまたはダイレクト）の **ルーム ID** を依頼者に登録すると、そのルームの受信が自動で紐付きます。未登録のルームからの受信は「未紐付けの連絡先」として届くので、そこから紐付けることもできます。

## 5. タスクの同期

- アプリで作成したタスクは「Chatwork にも作成」を選ぶとマイチャットのタスクとして登録されます
- 「Chatwork のタスクを取込」で、Chatwork 上の未完了タスクをアプリに取り込みます。Chatwork 側で完了するとアプリでも完了になります（毎時同期）

## 6. 制限

- ファイル送信は 5MB まで。超えるものは OneDrive の共有リンクとして送ります
- API は 5 分間に 300 リクエスト、投稿はルームごとに 10 秒間に 10 件までです

## 事務局からの伝言として使う場合

Chatwork の相手が依頼者ではなく事務所内の事務局メンバーである運用（伝言・連絡が中心）では、次の設定をします。

1. 設定 → 事務局メンバー に、伝言をくれる方を登録します。「Chatwork の参加ルームから候補を読み込む」で Chatwork のアカウントを選ぶと、その人からのメッセージを「事務局」として扱い、依頼者の未紐付け警告を出しません。
2. 事件ページの「担当事務局」で、その事件の担当者を選びます。事件から作る Chatwork タスク（受信箱の「タスク化」で「担当事務局の Chatwork タスクにも登録」を付けたものなど）は、この担当者に振られます。
3. 事件専用のグループチャットがある場合は、事件ページの「事件専用の Chatwork ルーム」で指定します。そのルームのメッセージはすべてその事件の記録に入ります。
4. 全体ルームの伝言は、本文に依頼者名（フルネーム・別名・2 文字以上の姓）があれば、その依頼者と進行中の事件に自動で紐付きます。判定できなかったものは会話画面の各メッセージの「紐付け」で指定します。

取込範囲を「自分宛だけ」にしている場合は、[To] で自分が指定された伝言、自分のメッセージへの返信（re）、全員宛（toall）、ダイレクトチャット、自分に振られたタスクのメッセージだけが受信箱に入ります。
