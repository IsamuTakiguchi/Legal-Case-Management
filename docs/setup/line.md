# LINE公式アカウント（Messaging API）の設定

## 1. Messaging API を有効化

1. [LINE Official Account Manager](https://manager.line.biz/) で対象アカウントを開く
2. 設定 → Messaging API → 「Messaging API を利用する」→ プロバイダーを作成または選択
3. 表示される **Channel ID** を控える

## 2. チャネル ID とシークレットを貼る（これだけ）

1. [LINE Developers Console](https://developers.line.biz/console/) で該当チャネルを開く
2. 「チャネル基本設定」タブの **チャネル ID** と **チャネルシークレット** を、アプリの初期設定画面に貼り付けて保存
3. 「接続テスト」を押す。アクセストークンの発行、Webhook URL の登録、疎通確認をアプリが自動で行います（トークンは 30 日有効で、期限前に自動更新します）

長期のチャネルアクセストークンを自分で発行して貼ることもできます（その場合は自動発行を使いません）。

## 3. 残る手動設定（2 か所の ON）

1. LINE Developers →「Messaging API 設定」→ **Webhook の利用** を ON（API では切り替えられないため）
2. 下の応答設定

## 4. 応答設定（重要）

Official Account Manager → 設定 → 応答設定:

- **チャット**: ON（管理画面からも手動でチャットできる状態を保つ）
- **Webhook**: ON
- あいさつメッセージ・応答メッセージ: 必要に応じて OFF

> 管理画面のチャットから手動で送った返信は、このアプリには取り込まれません（LINE の仕様上 Webhook に流れません）。返信はできるだけアプリから送ってください。逆に、アプリから送った返信は管理画面のチャットにも表示されます。

## 5. プランと通数

アプリからの返信は **プッシュメッセージ** として送信されるため、プランの通数を消費します。

| プラン | 月額 | 無料通数 | 超過 |
|---|---|---|---|
| コミュニケーション | 0 円 | 200 通 | 不可 |
| ライト | 5,000 円 | 5,000 通 | 不可 |
| スタンダード | 15,000 円 | 30,000 通 | 従量 |

`.env` の `LINE_MONTHLY_PUSH_LIMIT` にプランの通数を設定すると、設定画面とダッシュボードに当月の送信数が表示され、90% を超えると「要確認」に通知されます。

## 6. ファイルについて

Messaging API は PDF などのファイルを送信できません。アプリは次のように扱います。

- OneDrive に接続済みで匿名共有リンクが発行できる場合: 共有リンク（既定 30 日で失効）を本文に入れて送信
- 発行できない場合: 「管理画面のチャットから手動でお送りください」という案内文を本文に付け、ファイルは送信しません（Official Account Manager のチャットは 100MB までファイル送信可）

## 7. 依頼者の紐付け

LINE のユーザー ID は事前に分からないため、依頼者から最初のメッセージが届いたときに「未紐付けの連絡先」として要確認に表示されます。表示名を見て依頼者に紐付けると、以後は自動で振り分けられます。
