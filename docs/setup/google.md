# Google（Gmail・Google カレンダー）の設定

Google はアプリ登録を省略できません（Google の仕様）。ただし次の 3 つのリンクを順に開くだけで済みます。アプリの「初期設定」画面にも同じリンクがあります。

## 1. API の一括有効化（1 クリック）

[Gmail API と Calendar API をまとめて有効化](https://console.cloud.google.com/apis/enableflow?apiid=gmail.googleapis.com,calendar-json.googleapis.com) を開き、プロジェクトを選択（なければ「新しいプロジェクト」を作成）→「次へ」→「有効にする」。

## 2. OAuth 同意画面（重要）

「API とサービス」→「OAuth 同意画面」

- **Google Workspace を使っている場合**: ユーザーの種類を **内部** にする。審査もトークン期限もなく、これが最も簡単です
- **個人の Gmail の場合**: **外部** にし、アプリを **本番環境に公開** してください（「公開ステータス: テスト」のままだとリフレッシュトークンが **7 日で失効** し、受信が黙って止まります）。未確認アプリの警告は初回接続時に「詳細」→「（安全ではないページ）に移動」で進めます

スコープに以下を追加します。

- `https://www.googleapis.com/auth/gmail.modify`
- `https://www.googleapis.com/auth/calendar`
- `https://www.googleapis.com/auth/userinfo.email`

## 3. OAuth クライアント

1. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ **ウェブ アプリケーション**
2. 承認済みのリダイレクト URI に `https://<公開URL>/api/auth/google/callback` を追加（アプリの設定画面にも表示されます）
3. クライアント ID とシークレットを `.env` の `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` に設定

## 4. アプリから接続

アプリの設定画面 → 「Google に接続」→ 対象アカウントで同意。接続後は 2 分ごとに Gmail をポーリングし、15 分ごとにカレンダーを同期します。

## 4-2. Google アカウントでログインする

クライアント ID を設定すると、ログイン画面に「Google アカウントでログイン」が出ます。追加の登録は不要です（同じクライアント ID とリダイレクト URI を使います）。

- ログインできるのは、設定 → ログイン に登録したメールアドレスです。空のときは「Google に接続」したアカウントだけがログインできます
- 事務員など別のアカウントを許可する場合は、そのアドレスを設定に追加します
- パスワードでのログインも引き続き使えます（Google に問題があったときの予備）
- 許可していないアカウントでのログインは失敗として記録され、5 回失敗すると 15 分間ロックされます

## 5. カレンダーの使い方

- 左メニューの「予定」で、週・月・4 週間の一覧を切り替えて確認できます。「＋ 予定を追加」や各日の「＋」から登録し、各予定の「編集」「削除」で変更できます。登録・変更・削除は Google カレンダーにもそのまま反映されます（Google 未接続の間はアプリ内だけに保存され、「アプリ内」と表示されます）
- 種別を「期日」にして事件を選ぶと、その事件の「次回期日」にも反映されます
- Google カレンダー側で直接入れた予定は 15 分ごとに取り込まれます。すぐ反映したいときは「予定」画面の「Google カレンダーと同期」を押してください
- アプリが作るイベントには依頼者・事件・種別のタグ（拡張プロパティ）が付き、確実に紐付きます
- 手で入れたイベントは、タイトルに依頼者の姓（または別名）と「期日・弁論・尋問・判決・調停・審判・打合せ・面談・相談」などのキーワードが含まれていれば自動で分類されます
- 仮押さえは「{姓} {内容} 仮」というタイトルで **仮の予定（tentative）** として登録され、確定時に削除されます
- 期日・打合せの終了後に同じ依頼者の次回期日が見つからないと「次回期日が未入力」として通知します。複数の依頼者に同じ姓がいる場合は「別名」で区別してください

## 6. 別のカレンダーを使う場合

`GOOGLE_CALENDAR_ID` に対象カレンダーの ID（設定 → カレンダーの統合）を設定します。既定は `primary` です。
