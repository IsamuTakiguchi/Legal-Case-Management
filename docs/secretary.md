# AI 秘書

左メニューの **AI 秘書**（`/search`）で、日本語で頼むと、記録・予定・タスクを代わりに作ります。
依頼者や事件の ID を調べる必要はありません。秘書が自分で探します。

## 3 つの使い分け

| タブ | 使うとき |
|---|---|
| 秘書に頼む | 記録・予定・タスクを登録したいとき |
| AI に聞く | 「あの件どうなっている？」と事務所のデータに質問したいとき |
| そのまま探す | 語で探したいとき（AI を使わないので速い・無料） |

## 頼み方の例

- 「山田さんから電話。査定書は今週中に送るとのこと。届いたら内容を確認して連絡すると伝えた。記録しておいて」
- 「佐藤さんと 10 月 3 日 14 時から事務所で打合せを入れて」
- 「田中さんの件、来週金曜までに相手方へ回答するタスクを作って」
- 「山田さんから電話。査定書は今週中。記録して、10 月 3 日 14 時の打合せも入れて、到着を確かめるタスクも作って」（まとめて頼めます）

日付は「来週火曜」「あさって」でも通じます。今日を基準に読みます。

## 登録されるまでの流れ

1. 頼みごとを書いて「案を作ってもらう」を押す
2. 秘書が依頼者・事件を探し、予定を入れるときはその日の前後に重なりがないかを見る
3. **登録する内容** に案が並ぶ。件名・日時・事件・本文はその場で直せる。要らないものはチェックを外す
4. 「この内容で登録」を押して、はじめて保存される

**押すまでは何も登録されません。** 秘書が勝手に予定を入れたり、依頼者にメッセージを送ったりすることはありません。

## 秘書ができること・できないこと

できること

- 事件への記録の追加（電話・打合せ・期日・メモ・進捗・方針）
- 予定の登録（期日・打合せ・相談・仮押さえ・その他。Google カレンダーにも入ります）
- タスクの作成（対応中・依頼者の返事待ち・相手方や裁判所の返事待ち）
- 事務所のデータを調べて答える

できないこと

- メッセージの送信（送信は会話画面から。文面の下書きもそちらで）
- 依頼者・事件そのものの新規作成（依頼者ページ・事件ページから）
- 記録・予定・タスクの削除や書き換え

## 注意

- 記録は必ず事件に紐付きます。どの事件か 1 つに絞れないときは、秘書が聞き返します。そのまま続けて答えれば話が続きます。
- 記録は、これまでの電話メモと同じように、要旨・決定事項・次のアクションへ AI が整理して保存します。整理ができなかったときでも、書いた本文はそのまま残ります（事件ページで整理し直せます）。
- 言われていないことは足しません。金額・期限・相手の名前が足りなければ、案を作らずに聞き返します。
- Anthropic の API キーが必要です（初期設定で登録）。使った分は 設定 → API 利用料 に「AI 秘書」として出ます。
