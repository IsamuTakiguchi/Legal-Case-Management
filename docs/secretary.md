# AI 秘書

左メニューの **AI 秘書**（`/search`）で、日本語で頼むと、記録・予定・タスクの登録から、事件・依頼者・関係者の変更、タスク・予定の変更や削除、メッセージの送信まで、案を作って代わりに行います。
依頼者や事件の ID を調べる必要はありません。秘書が自分で探します。

## 3 つの使い分け

| タブ | 使うとき |
|---|---|
| 秘書に頼む | 登録・変更・削除・送信をしたいとき |
| AI に聞く | 「あの件どうなっている？」と事務所のデータに質問したいとき |
| そのまま探す | 語で探したいとき（AI を使わないので速い・無料） |

## 頼み方の例

- 「山田さんから電話。査定書は今週中に送るとのこと。届いたら内容を確認して連絡すると伝えた。記録しておいて」
- 「佐藤さんと 10 月 3 日 14 時から事務所で打合せを入れて」
- 「田中さんの件、来週金曜までに相手方へ回答するタスクを作って」
- 「山田さんから電話。査定書は今週中。記録して、10 月 3 日 14 時の打合せも入れて、到着を確かめるタスクも作って」（まとめて頼めます）
- 「吉堂さんの自己破産の担当を藤田さんにして」「田中さんの事件を残務処理にして」
- 「山田さんの答弁書のタスクを起案・検討完了にして」「佐藤さんの 10 月 3 日の打合せを 4 日の同じ時間に動かして」
- 「鈴木法律事務所の鈴木一郎弁護士を、田中さんの事件の相手方代理人に登録して」
- 「山田さんに、源泉徴収票を送ってほしいとメールして」

日付は「来週火曜」「あさって」でも通じます。今日を基準に読みます。

## 登録されるまでの流れ

1. 頼みごとを書いて「案を作ってもらう」を押す
2. 秘書が依頼者・事件・担当事務局・タスク・予定を探し、予定を入れるときはその日の前後に重なりがないかを見る
3. **登録する内容** に案が並ぶ。変更の案は、項目ごとに「いま」の値と変更後の値が並ぶ。中身はその場で直せる。要らないものはチェックを外す
4. 「この内容で登録」を押して、はじめて保存・変更・送信される

**押すまでは何も変わりません。** 秘書が勝手に予定を入れたり、依頼者にメッセージを送ったりすることはありません。送信と削除の案は赤い印で出ます。押すと取り消せないので、宛先・本文・対象を確かめてください。

## 秘書ができること・できないこと

できること

- 事件への記録の追加（電話・打合せ・期日・メモ・進捗・方針）
- 予定の登録・変更（日時・件名・場所・種類・仮押さえ/確定）・削除（Google カレンダーにも反映）
- タスクの作成・変更（対応中・起案・検討完了・待ち・完了などの状態、締切・返信期限、名前）・削除
- 事件の登録・変更（担当事務局・区分・段階・事件類型・裁判所・事件番号・方針メモ・紹介者・事件名）
- 依頼者の登録・変更（氏名・ふりがな・電話・メール・連絡手段・メモ）
- 事件の関係者（相手方代理人など）の追加・変更
- メッセージの送信（依頼者・窓口へ Gmail・LINE・Chatwork、関係者へ Gmail・LINE、事務局へ Chatwork）
- 事務所のデータを調べて答える

できないこと

- 記録の書き換え・削除（事件ページから）
- 依頼者・事件の削除（依頼者ページ・事件ページから）
- ファイルの操作や書面の作成（各画面から）

変更の案は、変える項目だけが入ります。項目を空にする（担当事務局を外す など）ときは「空にする」として出ます。

## 注意

- 記録は必ず事件に紐付きます。どの事件か 1 つに絞れないときは、秘書が聞き返します。そのまま続けて答えれば話が続きます。
- 記録は、これまでの電話メモと同じように、要旨・決定事項・次のアクションへ AI が整理して保存します。整理ができなかったときでも、書いた本文はそのまま残ります（事件ページで整理し直せます）。
- 言われていないことは足しません。金額・期限・相手の名前が足りなければ、案を作らずに聞き返します。
- Anthropic の API キーが必要です（初期設定で登録）。使った分は 設定 → API 利用料 に「AI 秘書」として出ます。
